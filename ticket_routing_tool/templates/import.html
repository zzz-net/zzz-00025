CSV格式说明

CSV文件必须包含以下列名，列顺序可以任意：

列名 类型 必填 说明
title 字符串 是 工单标题
content 字符串 是 工单详细内容
channel 字符串 否 工单来源渠道（email, phone, web, app, wechat, weibo）
tags 字符串 否 标签，多个标签用逗号分隔
queue 字符串 是 实际分派队列（训练数据必需）
提示：训练数据需要包含 queue 列作为标签，预测数据不需要此列。
